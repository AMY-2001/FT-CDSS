FIGURE 5 — PIPELINE PERFORMANCE EXPERIMENTAL LOG
==================================================================

Figure 5 reports performance under sequential and parallel execution:
(a) speedup, (b) throughput, (c) inference time, and (d) parallel fraction.

Experimental conditions
------------------------
Total samples processed: 2010
CPU cores used for parallel-fraction calculation: 4
Execution platform: Raspberry Pi

Definitions
-----------
Speedup = Sequential execution time / Parallel execution time
Throughput = Number of samples / Execution time
Inference time = Execution time / Number of samples
Parallel fraction = (1 - 1/Speedup) / (1 - 1/N)
where N = 4 CPU cores.

------------------------------------------------------------------
BASELINE
------------------------------------------------------------------
Sequential total execution time: 767.9200 s
Parallel total execution time:   410.2212 s

Speedup: 767.9200 / 410.2212 = 1.8719
Sequential throughput: 2010 / 767.9200 = 2.617 images/s
Parallel throughput:   2010 / 410.2212 = 4.8997 images/s
Sequential inference time: 767.9200 / 2010 = 0.382 s/image
Parallel inference time:   410.2212 / 2010 = 0.204 s/image
Parallel fraction: (1 - 1/1.871) / (1 - 1/4) = 62.070%
