Dataset:
FI campaign MRI brain-tumor dataset

Model:
ResNet18 (RN18)

Campaign scope:
This campaign records the effect of bitflip (upset) fault injection on classification accuracy for selected high-order (MSB) bit positions.
The campaign was reduced to the selected MSB positions because the experimental analysis showed that higher-order bits produced more significant accuracy degradation.

The values below are classification accuracy (%) for the corresponding
injection percentage and selected bit position.
