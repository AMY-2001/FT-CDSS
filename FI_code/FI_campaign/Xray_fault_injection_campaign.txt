Model: 
ResNet18 (RN18)

Dataset:
Chest X-ray (Pneumonia)

Purpose:
This campaign was conducted to characterize the effect of bit-level
fault injection on classification accuracy for the X-ray model.

Fault Types:
- SEU: Single Event Upset
- DNU: Double Node Upset
- TNU: Triple Node Upset
- QNU: Quadruple Node Upset

Injection Percentages:
10%, 20%, 30%, 40%, 50%, 60%

Bit Groups:
- SEU: bit group (7)
- DNU: bit group (6,7)
- TNU: bit group (5-7)
- QNU: bit group (4-7)

The campaign indicates that the effect of injected faults becomes more
pronounced as the injection percentage increases, particularly for
multi-bit upset faults. The results were used to identify the more
sensitive bit positions and to guide the subsequent fault-injection
experiments used in the study.
